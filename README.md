# डीलक्स सैलून

स्टैंडअलोन सैलून रेडियो — 90 के दशक के बॉलीवुड हिट्स और लाइव सिंक बोल।

## चलाएँ

```bash
npm install
npm run build
npm start
```

डेव:

```bash
npm run dev
```

[http://localhost:3000](http://localhost:3000) खोलें।

## विशेषताएँ

- हिंदी ब्रांडिंग (डीलक्स सैलून)
- चुने हुए 90 के सैलून बैंकर
- ऑडियो के साथ लाइव बोल
- रूम टोन, म्यूट, शेयर लिंक
